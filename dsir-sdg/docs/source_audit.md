# DSIR SDG source audit

Reference inspected on 2026-09-16: DSIR 0.9.0, commit
`e2ff6735d174769b55f9a3e55f9f36c75ce9f397`. Source and tests in the original
DSIR repository were read without modifying the package. The package's
`AGENTS.md` contains older 0.7.0 notes; executable 0.9.0 code takes precedence.

## Catalogue and observations

`R/sdg.R` implements `sdg_goals()`, `sdg_targets()`, `sdg_indicators()`,
`sdg_areas()`, `sdg_data()`, and `sdg_clean()`. Its base URL is
`https://unstats.un.org/sdgs/UNSDGAPIV5/v1/sdg/`.

- `Indicator/List` returns the official SDG indicator catalogue. The R search
  lowercases descriptions and applies literal substring matching with AND
  semantics. A single query string is split on whitespace. A character vector
  preserves a phrase within each element. It does not do semantic or fuzzy search.
- `GeoArea/List` supplies UN geographical area identifiers and descriptions.
- `Indicator/Data` receives repeated `indicator` and `areaCode` query keys.
  Comma-separated parameter values are unsafe: DSIR's regression tests document
  upstream filters being silently ignored with that representation.
- Pagination starts at `page=1`, uses `pageSize=1000` by default, and continues
  through `totalPages`. The documented maximum page size is 10000. The current R
  implementation combines nested columns using `vctrs::vec_rbind()` because
  different series have different dimension and attribute keys.
- Year bounds are inclusive and applied **after complete retrieval** using
  integer conversion of `timePeriodStart`. DSIR deliberately avoids sending
  `timePeriodStart`/`timePeriodEnd` filters: these have caused HTTP 500 responses
  and long delays in the UN service. If the time column is absent, R warns and
  returns unfiltered data; a skill must instead report that it cannot satisfy the
  requested year filter.
- An SDG indicator is not necessarily one time series. For example, vaccination
  indicator `3.b.1` has several vaccine series. `sdg_coverage()` in
  `R/sdg_coverage.R` retrieves data and groups by location and series to report
  year range and row count; it is not a cheap preflight availability endpoint.

## HTTP and failure behavior

`R/http.R::.dsi_request()` configures a 30-second timeout, three attempts,
exponential backoff capped at 30 seconds, retryable HTTP status codes
429/500/502/503/504, and retries for connection failures. In `R/sdg.R`,
`.sdg_get()` catches HTTP and JSON parsing failures, warns, and returns `NULL`.
`sdg_data()` then returns an empty tibble, discarding already fetched pages.

The skill retains timeout/retry concepts and discards incomplete retrievals,
but must not retain the ambiguous empty-table failure contract. A request error,
invalid catalogue identifier, valid query with no records, and records removed
by filters must have distinct outcomes. HTTP errors must never become a claim
that the UN has no data.

## Exact cleaned schema

`R/clean_schema.R` defines the ordered 15-column schema below. `sdg_clean()`
never deduplicates, aggregates, interpolates, or replaces censored values.

| Field | DSIR SDG behavior |
| --- | --- |
| `source` | Literal `sdg` |
| `id` | First element of raw `indicator` when a list; otherwise its character value |
| `indicator` | Raw `seriesDescription`; missing when not supplied |
| `location` | Raw `geoAreaCode` converted to character, preserving its representation |
| `iso3` | WHO Member State lookup after M49 integer conversion and zero-padding |
| `location_name` | DSIR `who_countries$name_short` for members; raw `geoAreaName` otherwise |
| `year` | Integer conversion of `timePeriodStart`; failed conversion is missing |
| `value` | Raw display value as character |
| `value_num` | Numeric conversion; values such as `<0.1` remain missing |
| `low`, `high` | Numeric conversion of `lowerBound`, `upperBound` |
| `series` | Raw SDG series code |
| `dim1`, `dim2`, `dim3` | Always missing; these are GHO schema fields |

Rows are stably ordered by character `location`, then integer `year`, with
missing sort keys last. Empty input retains the 15-column typed schema in R.
`id` can lose secondary SDG indicator links because only the first raw link is
selected. Units, nature, source, footnotes, nested dimensions, attributes,
additional indicator links, and original area names are **not** in these 15
columns. A separate enriched observation view must preserve this information;
displaying only DSIR's compact table could silently mix sexes, age groups, units,
or estimate types.

## Location and region metadata

- `data/who_countries.rda`, generated by `data-raw/who_countries.R`, is the
  versioned 194-member master table. It includes `iso3`, `iso2`, `m49_code`,
  `name_official`, `name_short`, `who_region`, and other classifications.
- `R/iso3_to_m49.R` maps case-insensitive member ISO3 codes to padded M49 strings.
  `R/m49_to_iso3.R` pads integer M49 inputs and maps members only. UN aggregates
  and non-member areas retain a missing ISO3 value.
- `.resolve_area()` accepts all-ISO3 or all-numeric M49 vectors, rejects mixed
  vectors and invalid formats, and drops unknown ISO3 inputs with a warning.
  The natural-language skill should resolve names explicitly and report unknown
  locations instead of silently narrowing the user's request.
- `data/*ro_cty.rda`, `wpro_cty.rda`, and `pic_cty.rda` are convenience WHO
  membership snapshots, not a historical membership database. `R/data.R` says
  WPR includes Indonesia after its May 2025 reassignment. They must not be used
  as permanent regional definitions.
- UN SDG regional aggregates use UN area codes and group definitions. WHO WPR,
  UN Oceania, and UN Eastern and South-Eastern Asia are different geographies.
  Never substitute one for another or compute an unweighted regional average.
  The live UN catalogue inspected for this release includes area `99047`,
  `WHO Western Pacific`. Resolve that official catalogue entry when applicable;
  its presence does not establish that every series supplies observations for
  it, or that its membership changes year by year.

## Tests inspected and implications

Inspected `tests/testthat/test-sdg-get-mock.R`, `test-sdg-area-resolution.R`,
`test-sdg-year-filter.R`, `test-sdg-indicators.R`, `test-sdg-coverage.R`,
`test-clean.R`, `test-iso3-to-m49.R`, and `test-m49_to_iso3.R`.

The strongest existing regression checks cover repeated query keys, complete
multi-page binding, unequal nested dimension columns, local year filtering,
HTTP/JSON failure, member-name precedence, M49 normalization, censored display
values, missing series codes, and typed empty outputs. Many R catalogue,
coverage, and year-filter tests require a live endpoint and are skipped on CRAN.
The skill should add deterministic offline API-envelope and truncation tests,
then live checks against verified catalogue identifiers.

## Reuse and intentional differences

Reuse the UN endpoint, repeated-key query encoding, year workaround, complete
pagination, WHO member mapping, display/numeric distinction, compact schema,
row multiplicity, and location/series coverage concept. Add catalogue validation,
small reviewed search aliases, explicit uncertainty, enriched metadata and
dimensions, provenance, strict paging checks, and distinguishable failure states.

Do not port R package installation, plotting, modelling, GHO routing, static
WHO-region expansion, soft HTTP failure as empty data, or the assumption that an
indicator uniquely identifies a comparable series. R is a development-only
parity reference, not a skill runtime dependency.

The parity harness in `evals/run_parity.py` and `evals/parity.R` compares the
original R cleaner with the skill over identical saved API rows. Its reports
separate live API snapshots from synthetic transformation fixtures, record source
hashes, and do not describe common-input cleaning checks as two independent live
retrievals.

The available R 4.6.0 installation contains DSIR 0.8.0. Therefore the harness
sources the current 0.9.0 functions and helpers and loads the source repository's
country asset in an isolated environment. It records both versions and whether
the installed function bodies match; the original source is the reference.
