Source data and host services

The software license does not relicense WHO or UN data, metadata or publications. Consult the original data provider for the terms applying to the specific dataset. Retain source attribution, units, definitions and release information with exported data.

Use of ChatGPT or another AI host is subject to that host's separate terms and account conditions. A plugin does not provide an account or subscription to the host.

Interpretation and limitations

These tools support analysis of public aggregate statistics, not individual diagnosis or treatment. Source APIs, definitions, data revisions and availability can change. Check provenance, completeness and comparability before using results. Missing data and request failures must not be interpreted as observed zero values.

For questions, use GitHub Issues. See the candidate privacy policy for data handling.
