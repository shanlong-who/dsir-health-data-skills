DSIR GHO Health Data Skill

Find WHO Global Health Observatory indicators, filter public observations by location, year and named dimensions, and export CSV and JSON with source details.

Maintained by Shanlong Ding. This is an independently maintained data tool, not an official WHO or OpenAI service. It provides public health statistics, not clinical advice.

Unreleased Phase 1 source

The 23 October 2026 GHO source repair defaults to legacy and supports explicit xMart, with no automatic fallback. Offline regressions, bounded live queries and independent same-backend checks passed. User-facing acceptance and a reviewed package build remain pending. Published ZIPs and installed plugins do not contain this source update. See the Phase 1 report for scope and evidence.

Historical published candidate: 7 October 2026

Plugin 0.1.3 uses GHO skill 0.1.1, which defaults to WHO xMart. Released DSIR 0.11.0 defaults to the legacy GHO OData API when its session option is unset. The Skill follows an earlier pinned xMart implementation; equal output columns do not establish equal source definitions, dimensions, releases or values. Always retain the backend and source details in response.json alongside the CSV.

The 7 October 2026 offline and common-input checks passed, while complete live retrieval and independent live parity remained unverified. Later narrow checks do not complete that suite. Requests that fail are reported as failures; no observations are invented. See the backend comparison guide.

The plugin requires Python 3.10+ and permitted HTTPS access in the host runtime. It has no maintainer-hosted backend.
