Privacy Policy

DSIR GHO Health Data Skill · Effective and last updated: 7 October 2026

Scope and maintainer

This policy describes the bundled DSIR GHO plugin and this website, maintained by Shanlong Ding. The plugin retrieves public WHO Global Health Observatory statistics. It is independently maintained and is not an official WHO or OpenAI service. It does not require a plugin account, WHO API key or payment details.

What the bundled client sends

The client sends requests directly from your agent runtime to WHO public xMart at xmart-api-public.who.int. If you explicitly select the legacy adapter, it uses ghoapi.azureedge.net. Requests include indicator and table identifiers, location and year filters, dimension codes, pagination parameters and standard HTTP headers. WHO also receives network information such as the runtime's IP address. Some read-only xMart queries use POST to send query parameters.

The bundled client does not send your full conversation, uploaded documents or patient records to a maintainer-operated server. The maintainer operates no backend for this plugin. Do not put personal or patient information into query parameters or use this public-data tool to process confidential records.

Outputs, storage and retention

The client processes returned public observations in the runtime. Exported CSV, JSON, provenance and diagnostic files are written to the output locations in that environment. Errors and diagnostics can contain request URLs, query parameters and source responses. The maintainer does not receive or store these files through a plugin backend.

Local or hosted runtime files remain until you or the host remove them under the host's storage rules. The plugin does not impose an automatic retention period. If you share an export, conversation or diagnostic report, the recipient may retain a copy.

Third-party services

ChatGPT or another agent host processes your prompts, files, tool execution and outputs under its own policies and account settings. WHO processes API requests under its own policies. Their logging, retention and deletion practices are outside the maintainer's control. See OpenAI's privacy policy and WHO's privacy policy.

This static website is hosted on GitHub Pages. It includes no site-authored analytics, advertising, tracking scripts, forms or cookies. GitHub may collect visitor information and security logs through hosting; see the GitHub General Privacy Statement.

Support information

If you open a GitHub issue, your GitHub identity and anything you include are visible publicly and may be used by the maintainer to respond to the issue. GitHub manages that information under its own policy. Do not post sensitive information or secrets.

Your choices and deletion

You can stop requests by not invoking or by disabling the plugin. Delete exported files in your runtime and manage conversations and uploaded files through the host's controls. For information you post on GitHub, use GitHub's editing, deletion and support controls. The maintainer cannot delete information held independently by OpenAI, WHO or GitHub.

Contact and updates

For questions about this policy, contact Shanlong Ding through the repository's GitHub Issues without including sensitive details. Material changes to the plugin's data handling will be reflected here with a new update date. The source history is available in the public repository.
